9차시: 함수 작성하기

R 기초 프로그래밍

오늘의 학습 목표

  1. 함수의 입력, 처리, 반환값을 구분할 수 있다.
  2. 한 가지 역할을 수행하는 간단한 함수를 작성할 수 있다.
  3. 기본값이 있는 인자와 이름이 있는 인자를 사용할 수 있다.
  4. 작성한 함수를 단일 값, 벡터, 데이터 프레임 열에 재사용할 수 있다.

선수 지식

  • 변수, 벡터, 조건문을 사용할 수 있습니다.
  • 데이터 프레임의 열을 선택할 수 있습니다.
  • 같은 작업을 반복문이나 벡터화 연산으로 적용할 수 있습니다.

반복되는 계산을 살펴본다

control_count_k <- 1240 / 1000
treated_count_k <- 1520 / 1000
another_count_k <- 1430 / 1000
  • 같은 계산을 여러 곳에서 반복하고 있습니다.
  • 계산 방법이 바뀌면 여러 줄을 모두 수정해야 합니다.
  • 계산에 이름을 붙여 재사용하면 코드를 관리하기 쉽습니다.

함수는 입력을 받아 작업하고 결과를 돌려준다

입력값 → 처리 과정 → 반환값
 1240  →  1000으로 나누기  →  1.24

R에서 이미 사용한 함수도 같은 구조를 가집니다.

mean(c(1200, 1350, 980))

함수의 기본 구조

function_name <- function(argument) {
  result <- argument를 사용한 계산
  return(result)
}
  • function_name: 함수에 붙이는 이름
  • argument: 함수가 받을 입력의 이름
  • { }: 함수가 수행할 코드
  • return(): 호출한 곳으로 돌려줄 결과

첫 번째 함수를 작성한다

to_thousands <- function(cell_count) {
  result <- cell_count / 1000
  return(result)
}

이 코드는 함수를 정의할 뿐, 아직 계산을 실행하지는 않습니다.

함수를 호출하면 코드가 실행된다

to_thousands(1240)
to_thousands(1520)

호출할 때 전달한 값이 함수 안의 cell_count에 들어갑니다.

함수의 세 부분을 구분한다

to_thousands <- function(cell_count) {
  result <- cell_count / 1000
  return(result)
}
부분 코드
입력 cell_count
처리 cell_count / 1000
반환 return(result)

반환값을 변수에 저장한다

control_count_k <- to_thousands(1240)
control_count_k
  • 함수의 결과는 다른 값처럼 변수에 저장할 수 있습니다.
  • 반환값을 다음 계산의 입력으로 사용할 수도 있습니다.

반환된 객체를 다시 저장해야 할 수 있다

cell_counts <- c(1350, 980, 1240)

sort(cell_counts)
cell_counts

cell_counts <- sort(cell_counts)
cell_counts
  • 많은 R 함수는 입력 객체를 직접 바꾸지 않고 처리한 결과를 반환합니다.
  • 결과를 계속 사용하려면 반환값을 변수에 저장합니다.
  • 같은 이름에 저장하면 이후 코드에서는 변경된 결과를 사용합니다.

분석 패키지에서도 같은 패턴을 사용한다

# 패키지 사용 예시: 이 차시에서는 실행하지 않습니다.
pbmc <- NormalizeData(pbmc)
pbmc <- ScaleData(pbmc)

두 코드 모두 다음 순서로 읽습니다.

현재 객체를 함수에 전달한다
→ 함수가 처리한 객체를 반환한다
→ 반환된 객체를 같은 이름에 다시 저장한다

함수가 원본을 직접 바꾸는지, 새 객체를 반환하는지는 도움말의 반환값 설명을 확인합니다.

마지막 표현식도 자동으로 반환된다

to_thousands <- function(cell_count) {
  cell_count / 1000
}

to_thousands(1240)
  • R은 함수에서 마지막으로 계산된 값을 자동 반환합니다.
  • 입문 단계에서는 반환 위치를 분명히 보여 주고 싶을 때 return()을 사용합니다.

print()와 return()은 역할이 다르다

show_cell_count <- function(cell_count) {
  print(cell_count)
}

double_cell_count <- function(cell_count) {
  result <- cell_count * 2
  return(result)
}
  • print()는 값을 화면에 보여 줍니다.
  • return()은 함수의 결과를 호출한 곳으로 돌려줍니다.

여러 입력을 받을 수 있다

calculate_retention <- function(raw_count, filtered_count) {
  retention <- filtered_count / raw_count
  return(retention)
}

calculate_retention(1500, 1200)

쉼표로 여러 인자를 구분합니다.

위치에 따라 인자를 전달한다

calculate_retention(1500, 1200)
  • 첫 번째 값은 raw_count에 들어갑니다.
  • 두 번째 값은 filtered_count에 들어갑니다.
  • 순서가 바뀌면 계산 결과도 달라질 수 있습니다.

이름을 적어 인자를 전달한다

calculate_retention(
  raw_count = 1500,
  filtered_count = 1200
)
  • 각 값의 의미가 분명해집니다.
  • 이름을 모두 적으면 순서를 바꾸어도 됩니다.
calculate_retention(filtered_count = 1200, raw_count = 1500)

인자에 기본값을 지정할 수 있다

passes_cell_count <- function(cell_count, min_cells = 1200) {
  result <- cell_count >= min_cells
  return(result)
}

min_cells를 생략하면 기본값 1200을 사용합니다.

passes_cell_count(1240)
passes_cell_count(1240, min_cells = 1300)

필수 인자와 기본 인자를 구분한다

passes_cell_count <- function(cell_count, min_cells = 1200) {
  cell_count >= min_cells
}
  • cell_count는 호출할 때 반드시 전달해야 합니다.
  • min_cells는 필요할 때만 다른 값으로 바꿉니다.
  • 필수 인자를 앞에, 기본값이 있는 인자를 뒤에 배치합니다.

하나의 함수는 한 가지 역할에 집중한다

calculate_retention <- function(raw_count, filtered_count) {
  filtered_count / raw_count
}

좋은 함수는 다음 질문에 답하기 쉽습니다.

  • 이 함수는 무엇을 계산하는가?
  • 어떤 입력이 필요한가?
  • 어떤 값을 반환하는가?

함수 이름은 동작을 나타내게 작성한다

calculate_retention()
passes_cell_count()
label_qc()
  • 함수 이름에도 snake_case를 사용합니다.
  • calculate, check, convert, label처럼 동작을 나타내는 단어가 유용합니다.
  • 이름만 보고 목적을 짐작할 수 있어야 합니다.

벡터화 연산을 사용한 함수는 벡터도 처리한다

cell_counts <- c(1240, 1385, 1090, 1520)

to_thousands(cell_counts)
passes_cell_count(cell_counts)

함수 안의 /와 >=가 벡터의 모든 원소에 적용됩니다.

데이터 프레임 열을 함수에 전달한다

sample_metadata <- read.csv("data/sample_metadata.csv")

sample_metadata$cell_count_k <-
  to_thousands(sample_metadata$cell_count)

head(sample_metadata)

함수를 한 번 정의한 뒤 여러 데이터에 같은 계산을 적용할 수 있습니다.

여러 QC 기준을 함수로 묶는다

passes_qc <- function(
  cell_count,
  median_genes,
  mito_percent,
  min_cells = 1200,
  min_genes = 2000,
  max_mito = 8
) {
  result <-
    cell_count >= min_cells &
    median_genes >= min_genes &
    mito_percent < max_mito

  return(result)
}

QC 함수를 단일 샘플에 사용한다

passes_qc(
  cell_count = 1240,
  median_genes = 2180,
  mito_percent = 4.2
)

각 인자 이름을 적으면 어떤 측정값을 전달하는지 분명합니다.

QC 수치는 함수 학습을 위한 예시이며 실제 분석 기준은 데이터와 실험 맥락에 따라 정해야 합니다.

QC 함수를 벡터에 사용한다

qc_result <- passes_qc(
  cell_count = sample_metadata$cell_count,
  median_genes = sample_metadata$median_genes,
  mito_percent = sample_metadata$mito_percent
)

qc_result

각 행의 같은 위치에 있는 값들이 함께 계산됩니다.

기본 기준을 바꾸어 재사용한다

strict_qc_result <- passes_qc(
  cell_count = sample_metadata$cell_count,
  median_genes = sample_metadata$median_genes,
  mito_percent = sample_metadata$mito_percent,
  min_cells = 1300,
  max_mito = 6
)

함수 본문을 수정하지 않고 호출할 때 기준을 바꿀 수 있습니다.

결과 레이블 함수는 별도로 작성한다

label_qc <- function(passed_qc) {
  label <- ifelse(passed_qc, "pass", "review")
  return(label)
}

label_qc(qc_result)

조건 계산과 문자 레이블 생성을 서로 다른 함수로 나누었습니다.

함수를 연결해 결과 열을 만든다

sample_metadata$qc_result <- qc_result
sample_metadata$qc_label <- label_qc(qc_result)

sample_metadata[, c("sample_id", "qc_result", "qc_label")]

작은 함수의 결과를 다음 함수의 입력으로 사용할 수 있습니다.

결측값을 처리하는 함수를 작성한다

label_doublet_rate <- function(doublet_rate, max_rate = 4) {
  label <- ifelse(
    is.na(doublet_rate),
    "missing",
    ifelse(doublet_rate <= max_rate, "pass", "review")
  )

  return(label)
}

먼저 결측값인지 확인한 뒤 측정값을 기준과 비교합니다.

함수 안의 변수는 지역 변수다

calculate_retention <- function(raw_count, filtered_count) {
  retention <- filtered_count / raw_count
  return(retention)
}

calculate_retention(1500, 1200)
  • retention은 함수가 실행되는 동안 함수 안에서 만들어집니다.
  • 함수 밖의 작업에 필요하면 반환값을 변수에 저장합니다.
sample_retention <- calculate_retention(1500, 1200)

함수 밖의 값을 몰래 사용하지 않는다

피해야 할 예:

# min_cells가 함수 밖에 있어야만 실행된다.
# passes_cell_count <- function(cell_count) {
#   cell_count >= min_cells
# }

권장 예:

passes_cell_count <- function(cell_count, min_cells = 1200) {
  cell_count >= min_cells
}

필요한 값은 인자로 명시합니다.

is.numeric()으로 입력 자료형을 확인한다

is.numeric(1240)
is.numeric("1240")

함수의 입력이 예상한 자료형인지 확인할 때 사용할 수 있습니다.

잘못된 입력에는 오류를 발생시킬 수 있다

to_thousands_checked <- function(cell_count) {
  if (!is.numeric(cell_count)) {
    stop("cell_count는 숫자형이어야 합니다.")
  }

  result <- cell_count / 1000
  return(result)
}

stop()은 설명이 포함된 오류를 발생시키고 함수 실행을 중단합니다.

올바른 입력과 잘못된 입력을 시험한다

to_thousands_checked(1240)

다음 코드는 입력 확인을 시험할 때 한 줄씩 실행합니다.

# to_thousands_checked("1240")

전체 실습 파일 실행을 막지 않도록 의도적 오류는 주석 처리합니다.

함수는 정의한 뒤에 호출한다

to_thousands <- function(cell_count) {
  cell_count / 1000
}

to_thousands(1240)

R 스크립트는 위에서 아래로 실행되므로 함수 정의가 호출보다 먼저 실행되어야 합니다.

함수를 작은 입력으로 확인한다

to_thousands(1000)
passes_cell_count(1200)
calculate_retention(100, 80)
  • 결과를 쉽게 예상할 수 있는 값을 사용합니다.
  • 경계값과 결측값도 확인합니다.
passes_cell_count(1199)
passes_cell_count(NA)

stopifnot()으로 예상 결과를 확인한다

stopifnot(to_thousands(1000) == 1)
stopifnot(passes_cell_count(1200) == TRUE)
stopifnot(calculate_retention(100, 80) == 0.8)
  • 조건이 모두 TRUE이면 아무것도 출력하지 않습니다.
  • 하나라도 FALSE이면 실행을 멈추므로 예상 결과 검증에 사용할 수 있습니다.

함수 위에 목적과 입력을 기록한다

# 필터링 후 남은 세포 비율을 계산한다.
# raw_count와 filtered_count는 같은 길이의 숫자형 값이다.
calculate_retention <- function(raw_count, filtered_count) {
  filtered_count / raw_count
}

코드만으로 알기 어려운 입력 조건과 단위를 주석으로 설명합니다.

흔한 오류 1: 함수를 정의만 하고 호출하지 않는다

to_thousands <- function(cell_count) {
  cell_count / 1000
}

to_thousands(1240)

함수 정의와 함수 호출은 서로 다른 단계입니다.

흔한 오류 2: 괄호나 중괄호를 닫지 않는다

passes_cell_count <- function(cell_count, min_cells = 1200) {
  result <- cell_count >= min_cells
  return(result)
}
  • 함수 이름 뒤의 ()와 본문을 감싸는 {}를 짝지어 작성합니다.
  • 코드를 들여쓰면 구조를 확인하기 쉽습니다.

흔한 오류 3: 반환할 값을 만들지 않는다

calculate_retention <- function(raw_count, filtered_count) {
  retention <- filtered_count / raw_count
  return(retention)
}

계산한 변수 이름과 return()에 적은 이름의 철자를 확인합니다.

실습 1: 단위 변환 함수 만들기

to_thousands <- function(cell_count) {
  result <- cell_count / 1000
  return(result)

to_thousands(1240)
to_thousands(c(1240, 1385, 1090))

단일 값과 벡터에서 모두 예상한 결과가 나오는지 확인합니다.

calculate_retention <- function(raw_count, filtered_count) {
  filtered_count / raw_count
}

passes_cell_count <- function(cell_count, min_cells = 1200) {
  cell_count >= min_cells
}

위치 인자, 이름이 있는 인자, 변경한 기본값으로 각각 호출합니다.

오늘 배운 내용

  • 함수는 입력을 받아 한 가지 작업을 수행하고 결과를 반환합니다.
  • 반환된 결과를 계속 사용하려면 변수에 다시 저장합니다.
  • 인자는 위치 또는 이름으로 전달하고 기본값을 지정할 수 있습니다.
  • 벡터화된 계산을 사용한 함수는 벡터와 데이터 프레임 열에도 재사용할 수 있습니다.
  • 필요한 값은 함수 밖에서 가져오지 않고 인자로 명시합니다.
  • 작은 입력과 stopifnot()으로 함수 결과를 확인할 수 있습니다.
