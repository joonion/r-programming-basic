1차시: R과 RStudio 시작하기

R 기초 프로그래밍

오늘의 학습 목표

  1. R과 RStudio의 역할을 구분할 수 있다.
  2. 콘솔과 스크립트에서 R 코드를 실행할 수 있다.
  3. 오류 메시지를 읽고 간단한 실행 오류를 수정할 수 있다.

전사체 분석에서 R이 필요한 이유

  • 많은 생명과학 분석 도구가 R로 제공됩니다.
  • 계산, 데이터 처리, 시각화를 한 환경에서 수행할 수 있습니다.
  • R 기초는 Seurat를 이해하고 사용하는 출발점입니다.

R은 프로그래밍 언어다

  • R은 데이터를 계산하고 분석하기 위한 프로그래밍 언어입니다.
  • 코드를 작성하면 같은 분석을 정확하게 반복할 수 있습니다.
  • 코드에는 분석 과정이 기록되므로 결과를 재현할 수 있습니다.

RStudio는 R을 사용하는 작업 환경이다

  • RStudio는 R 코드를 편리하게 작성하고 실행하도록 돕습니다.
  • R과 RStudio는 서로 다른 소프트웨어입니다.
  • 컴퓨터에 R이 먼저 설치되어 있어야 합니다.

RStudio의 네 개 창

창 주요 역할
Source 스크립트 작성
Console 명령 실행
Environment 생성된 객체 확인
Files·Plots·Packages·Help 파일, 그래프, 패키지, 도움말 확인

콘솔은 명령을 즉시 실행하는 곳이다

  • > 뒤에 명령을 입력합니다.
  • Enter를 누르면 명령이 즉시 실행됩니다.
  • 빠른 확인과 간단한 계산에 적합합니다.
10 + 5

스크립트는 코드를 기록하는 파일이다

  • R 스크립트는 .R 확장자를 사용합니다.
  • 여러 줄의 코드를 저장하고 다시 실행할 수 있습니다.
  • 실제 분석은 콘솔보다 스크립트를 중심으로 진행합니다.

R은 계산기처럼 사용할 수 있다

10 + 5
20 / 4
(3 + 2) * 4
  • 괄호를 사용하면 계산 순서를 지정할 수 있습니다.
  • 입력한 코드와 출력된 결과를 구분해서 읽습니다.

변수는 값에 붙이는 이름이다

cell_count <- 1250
  • 계산에 사용할 값을 이름으로 저장합니다.
  • 저장한 값은 같은 이름으로 다시 사용할 수 있습니다.
  • 의미가 분명한 이름을 사용하면 코드를 이해하기 쉽습니다.

<-는 값을 저장하는 연산자다

cell_count <- 1250

오른쪽의 1250을 왼쪽의 cell_count에 저장합니다.

  • 이 과정에서는 기본 대입 연산자로 <-를 사용합니다.

주석은 코드를 설명하는 메모다

# 세 샘플의 전체 세포 수를 계산한다.
total_cells <- 1200 + 1350 + 980
  • # 뒤의 내용은 실행되지 않습니다.
  • 코드의 목적이나 중요한 학습 포인트를 기록합니다.

첫 번째 R 스크립트 만들기

  1. File > New File > R Script를 선택합니다.
  2. 주석을 한 줄 입력합니다.
  3. labs/01_getting_started.R로 저장합니다.
# 1차시 실습: R과 RStudio 시작하기

한 줄의 코드를 실행하기

  1. 실행할 줄에 커서를 놓습니다.
  2. Ctrl + Enter를 누릅니다.
  3. Console에서 결과를 확인합니다.
cell_count <- 1250
cell_count

여러 줄의 코드를 실행하기

실행할 영역을 선택하고 Ctrl + Enter를 누릅니다.

control_cells <- 1200
treated_cells <- 1350
total_cells <- control_cells + treated_cells
total_cells

코드는 위에서 아래로 실행됩니다.

Environment에서 변수 확인하기

  • 실행된 변수는 Environment 창에 나타납니다.
  • 변수 이름과 현재 값을 확인할 수 있습니다.
  • 스크립트에 코드를 쓰는 것만으로는 변수가 생성되지 않습니다.

코드를 작성한 다음 반드시 실행해야 합니다.

오류 메시지를 읽는 첫 번째 방법

cell_count <- 1250
cell_cout
  1. 오류가 발생한 코드와 메시지를 함께 봅니다.
  2. 변수 이름의 철자를 먼저 확인합니다.
  3. 코드를 수정하고 해당 줄을 다시 실행합니다.

오늘 배운 내용

  • R은 코드를 실행하는 프로그래밍 언어입니다.
  • RStudio는 R 작업을 돕는 환경입니다.
  • Console은 즉시 실행하고, 스크립트는 코드를 기록합니다.
  • <-로 값을 변수에 저장합니다.
  • 오류 메시지는 문제를 수정하는 단서입니다.
