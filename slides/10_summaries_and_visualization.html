10차시: 데이터 요약과 시각화

R 기초 프로그래밍

오늘의 학습 목표

  1. 전체 데이터와 그룹별 데이터를 기초 통계량으로 요약할 수 있다.
  2. 분석 질문과 자료형에 맞는 ggplot2 그래프를 선택할 수 있다.
  3. 그래프를 객체로 저장하고 patchwork로 조합할 수 있다.
  4. 요약표와 그래프를 파일로 저장하고 확인할 수 있다.

선수 지식

  • CSV 파일을 데이터 프레임으로 불러올 수 있습니다.
  • 데이터 프레임의 열을 선택하고 조건으로 행을 선택할 수 있습니다.
  • 함수를 호출하고 인자를 이름으로 지정할 수 있습니다.

이번 차시의 분석 흐름

데이터 확인
  ↓
전체 요약
  ↓
그룹별 요약
  ↓
질문에 맞는 그래프 선택
  ↓
표와 그래프 저장

숫자만 계산하는 데서 끝나지 않고 결과가 무엇을 의미하는지 해석합니다.

샘플 메타데이터를 불러온다

sample_metadata <- read.csv("data/sample_metadata.csv")

head(sample_metadata)
str(sample_metadata)

요약과 시각화 전에 행 수, 열 이름, 자료형을 먼저 확인합니다.

분석 질문을 먼저 정한다

이번 차시에서는 다음 질문을 살펴봅니다.

  1. 각 실험 조건에는 샘플이 몇 개 있는가?
  2. 세포 수는 어느 범위에 분포하는가?
  3. 조건별 세포 수에 차이가 있는가?
  4. 세포 수와 검출 유전자 수는 어떤 관계가 있는가?

질문이 정해져야 필요한 요약과 그래프를 선택할 수 있습니다.

summary()로 전체 모습을 확인한다

summary(sample_metadata)
  • 숫자형 열의 최솟값, 사분위수, 중앙값, 평균, 최댓값
  • 논리형 열의 TRUE, FALSE 개수
  • 결측값이 있는 열의 NA's 개수

한 숫자형 열을 요약한다

cell_counts <- sample_metadata$cell_count

min(cell_counts)
max(cell_counts)
mean(cell_counts)
median(cell_counts)

각 함수는 데이터의 서로 다른 특징을 보여 줍니다.

평균과 중앙값을 구분한다

  • 평균: 모든 값을 더한 뒤 개수로 나눈 값
  • 중앙값: 값을 정렬했을 때 가운데에 있는 값
mean(cell_counts)
median(cell_counts)

극단적으로 크거나 작은 값이 있으면 평균과 중앙값이 달라질 수 있습니다.

범위와 사분위 범위를 확인한다

range(cell_counts)
quantile(cell_counts)
IQR(cell_counts)
  • range()는 최솟값과 최댓값을 반환합니다.
  • quantile()은 사분위수를 보여 줍니다.
  • IQR()은 3사분위수와 1사분위수의 차이입니다.

표준편차는 값이 퍼진 정도를 나타낸다

sd(cell_counts)
  • 표준편차가 작으면 값들이 평균 주변에 모여 있습니다.
  • 표준편차가 크면 값들이 더 넓게 퍼져 있습니다.
  • 서로 다른 단위의 변수는 표준편차만으로 직접 비교하지 않습니다.

결측값이 있으면 먼저 확인한다

doublet_rates <- sample_metadata$doublet_rate

is.na(doublet_rates)
sum(is.na(doublet_rates))
mean(doublet_rates)

결측값이 포함되면 기본 평균 결과도 NA입니다.

필요한 경우 결측값을 제외하고 요약한다

mean(doublet_rates, na.rm = TRUE)
median(doublet_rates, na.rm = TRUE)

na.rm = TRUE를 사용하기 전에 결측 원인과 제외 가능 여부를 판단해야 합니다.

범주별 개수를 table()로 센다

condition_counts <- table(sample_metadata$condition)
condition_counts

table()은 각 고유한 값이 몇 번 나타나는지 계산합니다.

두 범주를 함께 교차 집계한다

table(
  sample_metadata$condition,
  sample_metadata$passed_qc
)

행은 실험 조건, 열은 QC 통과 여부가 되어 조합별 개수를 보여 줍니다.

비율로 바꾸어 볼 수 있다

condition_counts / sum(condition_counts)
prop.table(condition_counts)

prop.table()은 전체 합이 1이 되도록 개수를 비율로 변환합니다.

그룹별 요약은 나누고 계산하는 과정이다

control 값들 ─→ 평균 계산
treated 값들 ─→ 평균 계산

그룹 변수와 요약할 숫자형 변수가 필요합니다.

sample_metadata$condition
sample_metadata$cell_count

tapply()로 그룹별 한 값을 계산한다

mean_cell_counts <- tapply(
  sample_metadata$cell_count,
  sample_metadata$condition,
  mean
)

mean_cell_counts
  1. 첫 번째 인자: 요약할 값
  2. 두 번째 인자: 그룹
  3. 세 번째 인자: 적용할 함수

다른 요약 함수도 적용할 수 있다

tapply(
  sample_metadata$cell_count,
  sample_metadata$condition,
  median
)

tapply(
  sample_metadata$cell_count,
  sample_metadata$condition,
  sd
)

같은 그룹 기준에 여러 요약 함수를 적용해 비교할 수 있습니다.

결측값이 있는 열을 그룹별로 요약한다

tapply(
  sample_metadata$doublet_rate,
  sample_metadata$condition,
  mean,
  na.rm = TRUE
)

na.rm = TRUE가 mean()으로 전달되어 그룹별 결측값을 제외합니다.

aggregate()는 결과를 데이터 프레임으로 만든다

condition_summary <- aggregate(
  cell_count ~ condition,
  data = sample_metadata,
  FUN = mean
)

condition_summary
  • cell_count ~ condition은 조건별 세포 수를 뜻합니다.
  • 결과가 표 형태라 저장하거나 다른 열을 추가하기 쉽습니다.

여러 숫자형 열을 함께 요약한다

condition_summary <- aggregate(
  cbind(cell_count, median_genes, mito_percent) ~ condition,
  data = sample_metadata,
  FUN = mean
)

condition_summary

cbind()로 함께 요약할 숫자형 열을 묶습니다.

그룹별 샘플 수를 요약표에 추가한다

condition_counts <- table(sample_metadata$condition)

condition_summary$sample_count <- as.integer(
  condition_counts[condition_summary$condition]
)

condition_summary

같은 조건 이름을 이용해 개수를 올바른 행에 연결합니다.

표시할 자릿수를 정리한다

condition_summary$cell_count <-
  round(condition_summary$cell_count, digits = 1)

condition_summary$mito_percent <-
  round(condition_summary$mito_percent, digits = 2)
  • round()는 표시할 소수점 자릿수를 정리합니다.
  • 원본 측정값을 바꾸기보다 요약 결과의 표시를 정리합니다.

dplyr로 그룹별 요약을 읽기 쉽게 표현한다

library(dplyr)

dplyr_summary <- sample_metadata %>%
  group_by(condition) %>%
  summarise(
    mean_cells = mean(cell_count),
    .groups = "drop"
  )

dplyr_summary

기본 R의 tapply()와 aggregate()를 다른 문법으로 표현한 것입니다.

group_by()는 뒤의 계산에 사용할 그룹을 지정한다

grouped_metadata <- sample_metadata %>%
  group_by(condition)

grouped_metadata
  • 데이터의 행이 즉시 분리되는 것은 아닙니다.
  • 객체에 그룹 정보가 추가됩니다.
  • 이후 summarise()와 slice_head() 등이 그룹별로 동작합니다.

summarise()는 그룹마다 요약 행을 만든다

condition_summary_dplyr <- sample_metadata %>%
  group_by(condition) %>%
  summarise(
    sample_count = n(),
    mean_cells = mean(cell_count),
    median_cells = median(cell_count),
    mean_mito = mean(mito_percent),
    .groups = "drop"
  )

condition_summary_dplyr
  • n()은 각 그룹의 행 개수를 반환합니다.
  • 각 요약식은 결과 데이터의 한 열이 됩니다.

결측값 처리는 기존 함수와 같다

doublet_summary <- sample_metadata %>%
  group_by(condition) %>%
  summarise(
    mean_doublet = mean(doublet_rate, na.rm = TRUE),
    missing_count = sum(is.na(doublet_rate)),
    .groups = "drop"
  )

데이터 마스킹으로 열 이름을 직접 쓰지만 mean()과 is.na()의 의미는 같습니다.

ungroup()은 그룹 상태를 제거한다

grouped_metadata <- sample_metadata %>%
  group_by(condition)

ungrouped_metadata <- grouped_metadata %>%
  ungroup()
  • 그룹 상태가 필요 없어진 시점에 제거할 수 있습니다.
  • summarise(.groups = "drop")도 요약 후 그룹을 제거합니다.

arrange()는 행의 순서를 정한다

sample_metadata %>%
  arrange(desc(cell_count))
  • arrange(cell_count)는 작은 값부터 정렬합니다.
  • desc(cell_count)는 큰 값부터 정렬합니다.
  • 원본 데이터의 값은 바뀌지 않고 행 순서만 달라집니다.

slice_head()는 그룹마다 처음 n개 행을 선택한다

top_samples <- sample_metadata %>%
  group_by(condition) %>%
  arrange(desc(cell_count)) %>%
  slice_head(n = 2) %>%
  ungroup()

top_samples

먼저 정렬한 뒤 slice_head()를 사용해야 큰 값 순서의 상위 행을 선택할 수 있습니다.

Seurat 마커 결과도 같은 흐름으로 정리한다

top_markers <- pbmc_markers %>%
  group_by(cluster) %>%
  filter(avg_log2FC > 1) %>%
  arrange(desc(avg_log2FC)) %>%
  slice_head(n = 2) %>%
  ungroup()

공식 PBMC 튜토리얼의 그룹별 상위 마커 선택과 같은 구조입니다.

그래프는 질문에 맞게 선택한다

질문 그래프
범주별 개수는 몇 개인가? 막대그래프
숫자형 값은 어떻게 분포하는가? 히스토그램
그룹별 분포가 어떻게 다른가? 상자그림
두 숫자형 변수는 어떤 관계인가? 산점도

한 그래프에 모든 정보를 넣기보다 질문 하나에 집중합니다.

막대그래프로 범주별 개수를 비교한다

condition_counts <- table(sample_metadata$condition)

barplot(condition_counts)
  • 막대의 높이는 각 범주의 개수입니다.
  • 범주형 자료의 빈도를 비교할 때 사용합니다.

막대그래프에 설명을 추가한다

barplot(
  condition_counts,
  main = "실험 조건별 샘플 수",
  xlab = "실험 조건",
  ylab = "샘플 수",
  col = c("#4472C4", "#ED7D31")
)
  • main: 그래프 제목
  • xlab, ylab: 축 이름
  • col: 막대 색상

그룹별 평균도 막대그래프로 표현할 수 있다

barplot(
  mean_cell_counts,
  main = "조건별 평균 세포 수",
  xlab = "실험 조건",
  ylab = "평균 세포 수",
  col = c("#4472C4", "#ED7D31")
)

평균 막대만으로는 각 값의 분포가 보이지 않는다는 한계가 있습니다.

히스토그램은 숫자형 값의 분포를 보여 준다

hist(sample_metadata$cell_count)
  • x축은 값의 구간입니다.
  • y축은 각 구간에 속한 관측값의 개수입니다.
  • 샘플 수가 적으면 분포 해석에 주의합니다.

히스토그램에 설명을 추가한다

hist(
  sample_metadata$cell_count,
  breaks = 4,
  main = "샘플별 세포 수 분포",
  xlab = "세포 수",
  ylab = "빈도",
  col = "#70AD47",
  border = "white"
)

breaks는 값을 나눌 구간 수에 영향을 줍니다.

상자그림은 그룹별 분포를 비교한다

boxplot(
  cell_count ~ condition,
  data = sample_metadata
)
  • 상자 안의 굵은 선은 중앙값입니다.
  • 상자는 가운데 50%의 값이 있는 범위를 나타냅니다.
  • 그룹별 값의 중심과 퍼짐을 비교할 수 있습니다.

상자그림에 설명을 추가한다

boxplot(
  cell_count ~ condition,
  data = sample_metadata,
  main = "실험 조건별 세포 수",
  xlab = "실험 조건",
  ylab = "세포 수",
  col = c("#4472C4", "#ED7D31")
)

표본 수가 매우 적을 때는 상자 모양만으로 차이를 단정하지 않습니다.

산점도는 두 숫자형 변수의 관계를 보여 준다

plot(
  sample_metadata$cell_count,
  sample_metadata$median_genes
)

각 점은 샘플 하나를 나타냅니다.

산점도에 설명과 점 모양을 추가한다

plot(
  sample_metadata$cell_count,
  sample_metadata$median_genes,
  main = "세포 수와 검출 유전자 수의 관계",
  xlab = "세포 수",
  ylab = "검출 유전자 수 중앙값",
  pch = 19,
  col = "#4472C4"
)
  • pch = 19는 채워진 원을 사용합니다.
  • 산점도에서 x축과 y축에 어떤 변수를 놓았는지 명확히 표시합니다.

조건에 따라 점 색상을 지정할 수 있다

point_colors <- ifelse(
  sample_metadata$condition == "control",
  "#4472C4",
  "#ED7D31"
)

plot(
  sample_metadata$cell_count,
  sample_metadata$median_genes,
  pch = 19,
  col = point_colors,
  xlab = "세포 수",
  ylab = "검출 유전자 수 중앙값"
)

색상은 데이터와 같은 길이의 벡터로 지정할 수 있습니다.

범례로 색상의 의미를 설명한다

legend(
  "bottomright",
  legend = c("control", "treated"),
  col = c("#4472C4", "#ED7D31"),
  pch = 19
)

색상이나 모양으로 그룹을 구분했다면 범례를 함께 제공합니다.

그래프 제목은 내용을 구체적으로 적는다

피해야 할 제목:

결과 그래프

권장 제목:

실험 조건별 세포 수
세포 수와 검출 유전자 수의 관계

제목만 읽어도 무엇을 보여 주는지 알 수 있게 작성합니다.

축 이름에는 변수와 단위를 적는다

xlab = "미토콘드리아 유전자 비율 (%)"
ylab = "세포 수"
  • 열 이름을 그대로 복사하기보다 사람이 이해할 표현을 사용합니다.
  • 단위가 있으면 괄호 안에 표시합니다.

ggplot2는 같은 문법으로 여러 그래프를 만든다

# 콘솔에서 한 번만 실행
# install.packages("ggplot2")
# install.packages("patchwork")

library(ggplot2)
library(patchwork)
  • 기본 R 그래프는 빠른 확인에 유용합니다.
  • ggplot2는 데이터, 표현 규칙, 그래프 종류를 층으로 조합합니다.
  • patchwork는 완성된 그래프 여러 개를 한 화면에 배치합니다.

그래프는 데이터, aes(), geom_*()에서 시작한다

ggplot(
  data = sample_metadata,
  mapping = aes(x = cell_count, y = median_genes)
) +
  geom_point()
  1. data: 사용할 데이터 프레임
  2. aes(): 열을 축, 색상 등에 연결하는 규칙
  3. geom_*(): 점, 막대, 상자와 같은 표현 방법

aes()에서도 데이터 마스킹 문법을 사용한다

ggplot(sample_metadata,
       aes(x = cell_count, y = median_genes,
           color = condition)) +
  geom_point(size = 3)

aes() 안에서는 sample_metadata$cell_count 대신 열 이름을 바로 씁니다. 7차시의 filter()와 같은 데이터 마스킹 문법입니다.

연결할 값과 고정할 값은 위치가 다르다

# condition 값에 따라 색상이 달라진다.
aes(color = condition)

# 모든 점을 같은 색으로 그린다.
geom_point(color = "#2563EB")

데이터 열과 연결할 값은 aes() 안에, 고정할 값은 밖에 둡니다.

질문에 맞는 geom_*()을 선택한다

ggplot(sample_metadata, aes(x = condition)) +
  geom_bar()

ggplot(sample_metadata, aes(x = cell_count)) +
  geom_histogram(binwidth = 150)

ggplot(sample_metadata,
       aes(x = condition, y = cell_count)) +
  geom_boxplot()

그래프를 해석할 때 주의한다

  • 그래프에서 보이는 차이가 항상 중요한 생물학적 차이는 아닙니다.
  • 샘플 수가 적으면 우연한 패턴일 수 있습니다.
  • 상관관계가 원인과 결과를 의미하지는 않습니다.
  • 축 범위와 결측값 처리 방법도 함께 확인합니다.

오늘 배운 내용

  • 전체 요약과 그룹별 요약은 서로 다른 질문에 답합니다.
  • table(), tapply(), aggregate()로 그룹 정보를 요약할 수 있습니다.
  • dplyr의 group_by()와 summarise()로 그룹별 요약표를 만들 수 있습니다.
  • arrange()와 slice_head()로 그룹별 상위 행을 선택할 수 있습니다.
  • 질문과 자료형에 맞춰 막대그래프, 히스토그램, 상자그림, 산점도를 선택합니다.
  • 제목, 축 이름, 범례로 그래프의 의미를 설명합니다.
  • 요약표는 write.csv(), 그래프는 png()와 dev.off()로 저장합니다.
