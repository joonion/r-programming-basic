3차시: 벡터와 인덱싱

R 기초 프로그래밍

오늘의 학습 목표

  1. 같은 종류의 여러 값을 벡터로 만들 수 있다.
  2. 위치, 이름, 조건을 이용해 벡터의 일부를 선택할 수 있다.
  3. 벡터에 연산과 기초 통계 함수를 적용할 수 있다.
  4. 결측값이 포함된 벡터를 확인하고 요약할 수 있다.

선수 지식

  • <-로 값을 변수에 저장할 수 있습니다.
  • 숫자형, 문자형, 논리형을 구분할 수 있습니다.
  • class(), is.na()로 객체를 확인할 수 있습니다.

2차시 복습: 변수 하나에 값 하나 저장하기

control_1_cells <- 1200
control_2_cells <- 1350
treated_1_cells <- 980
  • 변수가 많아질수록 같은 코드를 반복해서 작성하게 됩니다.
  • 여러 값을 하나의 객체로 묶으면 함께 처리하기 쉽습니다.

벡터는 여러 값을 순서대로 모은 객체다

cell_counts <- c(1200, 1350, 980)
cell_counts
  • c()는 여러 값을 하나로 결합합니다.
  • 벡터의 각 값을 원소라고 합니다.
  • 원소는 입력한 순서대로 저장됩니다.

문자형과 논리형 벡터도 만들 수 있다

sample_names <- c("control_1", "control_2", "treated_1")
passed_qc <- c(TRUE, TRUE, FALSE)

sample_names
passed_qc

벡터는 숫자뿐 아니라 문자와 논리값도 담을 수 있습니다.

벡터의 원소는 같은 자료형을 가진다

mixed_values <- c(1200, "control_1", TRUE)
mixed_values
class(mixed_values)
  • R은 하나의 벡터에서 원소의 자료형을 맞춥니다.
  • 위 예에서는 모든 값이 문자형으로 변환됩니다.
  • 서로 다른 종류의 정보를 한 벡터에 섞지 않는 것이 좋습니다.

벡터의 값과 구조를 확인한다

cell_counts <- c(1200, 1350, 980)

cell_counts
class(cell_counts)
typeof(cell_counts)
length(cell_counts)
  • class()와 typeof()는 자료형을 확인합니다.
  • length()는 원소의 개수를 반환합니다.

규칙적인 숫자 벡터를 만들 수 있다

sample_numbers <- 1:5
sample_numbers

even_numbers <- seq(from = 2, to = 10, by = 2)
even_numbers
  • :는 1씩 증가하거나 감소하는 연속된 숫자를 만듭니다.
  • seq()는 시작, 끝, 간격을 지정할 수 있습니다.

같은 값을 반복할 수 있다

control_labels <- rep("control", times = 3)
control_labels

qc_flags <- rep(TRUE, times = 4)
qc_flags

rep()는 같은 값이나 벡터를 지정한 횟수만큼 반복합니다.

인덱싱은 필요한 원소를 선택하는 방법이다

cell_counts <- c(1200, 1350, 980)
cell_counts[1]
  • 대괄호 [] 안에 선택 기준을 작성합니다.
  • R의 위치 번호는 1부터 시작합니다.
  • cell_counts[1]은 첫 번째 원소를 선택합니다.

위치로 여러 원소를 선택한다

cell_counts <- c(1200, 1350, 980, 1420)

cell_counts[c(1, 3)]
cell_counts[2:4]
  • 선택할 위치도 벡터로 전달할 수 있습니다.
  • 선택 결과 역시 벡터입니다.

음수 위치는 해당 원소를 제외한다

cell_counts <- c(1200, 1350, 980, 1420)

cell_counts[-1]
cell_counts[-c(1, 3)]
  • 음수 위치는 그 위치를 빼고 나머지를 선택합니다.
  • 양수 위치와 음수 위치를 한 번에 섞어 사용할 수 없습니다.

벡터의 원소에 이름을 붙일 수 있다

cell_counts <- c(
  control_1 = 1200,
  control_2 = 1350,
  treated_1 = 980
)

cell_counts
names(cell_counts)

이름을 붙이면 각 값이 어떤 샘플에 해당하는지 알기 쉽습니다.

이름으로 원소를 선택한다

cell_counts["control_2"]
cell_counts[c("control_1", "treated_1")]
  • 위치를 외우지 않고 의미 있는 이름으로 선택할 수 있습니다.
  • 이름은 따옴표로 감싼 문자형 값입니다.

비교 연산은 논리형 벡터를 만든다

cell_counts <- c(1200, 1350, 980, 1420)

cell_counts >= 1200

각 원소를 1200과 비교하여 TRUE 또는 FALSE를 반환합니다.

논리형 벡터로 원소를 선택한다

enough_cells <- cell_counts >= 1200
enough_cells

cell_counts[enough_cells]
  • TRUE인 위치의 원소만 선택됩니다.
  • 비교와 선택을 한 줄로 작성할 수도 있습니다.
cell_counts[cell_counts >= 1200]

문자형 벡터도 조건으로 선택할 수 있다

conditions <- c("control", "control", "treated", "treated")
cell_counts <- c(1200, 1350, 980, 1420)

conditions == "treated"
cell_counts[conditions == "treated"]

두 벡터의 같은 위치가 같은 샘플을 나타내도록 순서를 맞춰야 합니다.

벡터 연산은 모든 원소에 적용된다

cell_counts <- c(1200, 1350, 980)

cell_counts + 100
cell_counts * 2
cell_counts / 1000
  • 반복문을 작성하지 않아도 각 원소에 계산이 적용됩니다.
  • 이를 벡터화 연산이라고 합니다.

같은 길이의 벡터끼리 계산할 수 있다

raw_counts <- c(1200, 1350, 980)
filtered_counts <- c(1100, 1250, 900)

removed_counts <- raw_counts - filtered_counts
removed_counts

같은 위치의 원소끼리 계산됩니다.

벡터 길이가 다르면 주의한다

cell_counts <- c(1200, 1350, 980, 1420)
offsets <- c(10, 20)

cell_counts + offsets
  • 짧은 벡터가 반복되어 계산될 수 있습니다.
  • 이를 재활용 규칙이라고 합니다.
  • 의도하지 않은 계산을 피하려면 벡터 길이를 먼저 확인합니다.

기초 통계 함수로 벡터를 요약한다

cell_counts <- c(1200, 1350, 980, 1420)

sum(cell_counts)
mean(cell_counts)
median(cell_counts)
min(cell_counts)
max(cell_counts)

여러 값을 하나의 대표값으로 요약할 수 있습니다.

summary()로 여러 요약값을 확인한다

summary(cell_counts)

summary()는 최솟값, 사분위수, 중앙값, 평균, 최댓값을 함께 보여 줍니다.

NA가 있으면 요약 결과도 NA가 된다

cell_counts <- c(1200, 1350, NA, 1420)

mean(cell_counts)

알 수 없는 값이 포함되어 있으므로 평균도 바로 계산할 수 없습니다.

na.rm = TRUE로 결측값을 제외할 수 있다

mean(cell_counts, na.rm = TRUE)
sum(cell_counts, na.rm = TRUE)
  • na.rm은 결측값 제거 여부를 정하는 인자입니다.
  • TRUE로 지정하면 NA를 제외하고 계산합니다.
  • 결측값을 제외해도 되는지는 분석 목적에 따라 판단해야 합니다.

결측값의 위치와 개수를 확인한다

is.na(cell_counts)
sum(is.na(cell_counts))
  • is.na()는 각 원소가 결측값인지 확인합니다.
  • R에서 TRUE는 계산할 때 1처럼 사용할 수 있습니다.
  • 따라서 sum(is.na(...))는 결측값의 개수를 셉니다.

실습 1: 벡터 만들고 확인하기

sample_names <- c("control_1", "control_2", "treated_1")
cell_counts <- c(1200, 1350, 980)
passed_qc <- c(TRUE, TRUE, FALSE)

각 벡터의 값, 자료형, 길이를 확인합니다.

실습 2: 필요한 원소 선택하기

cell_counts[2]
cell_counts[c(1, 3)]
cell_counts[cell_counts >= 1200]

위치 선택과 조건 선택의 결과를 비교합니다.

실습 3: 벡터 계산하고 요약하기

filtered_counts <- c(1100, 1250, 900)
removed_counts <- cell_counts - filtered_counts

removed_counts
mean(filtered_counts)
max(filtered_counts)

어떤 샘플의 제거된 세포 수가 가장 많습니까?

실습 4: 결측값 다루기

gene_counts <- c(18000, NA, 19500)

is.na(gene_counts)
sum(is.na(gene_counts))
mean(gene_counts, na.rm = TRUE)

na.rm = TRUE를 사용하기 전후의 평균 결과를 비교합니다.

오늘 배운 내용

  • c()로 같은 종류의 여러 값을 벡터로 만듭니다.
  • [] 안에 위치, 이름, 조건을 지정하여 원소를 선택합니다.
  • 벡터화 연산은 각 원소에 같은 계산을 적용합니다.
  • mean(), sum() 등의 함수로 벡터를 요약합니다.
  • NA가 있으면 확인한 뒤 필요할 때 na.rm = TRUE를 사용합니다.

  3. 조건 인덱싱에서 어떤 위치의 원소가 선택됩니까?
