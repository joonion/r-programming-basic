4차시: 행렬과 팩터

R 기초 프로그래밍

오늘의 학습 목표

  1. 벡터를 행과 열로 배치하여 행렬을 만들 수 있다.
  2. 행렬의 구조를 확인하고 필요한 행, 열, 원소를 선택할 수 있다.
  3. 행과 열 방향으로 기초 요약값을 계산할 수 있다.
  4. 범주형 데이터를 팩터로 표현하고 수준을 확인할 수 있다.

선수 지식

  • c()로 벡터를 만들 수 있습니다.
  • 위치, 이름, 조건을 사용해 벡터의 원소를 선택할 수 있습니다.
  • 숫자형, 문자형, 논리형 자료를 구분할 수 있습니다.

행렬은 같은 자료형의 값을 행과 열로 배치한다

        cell_1  cell_2  cell_3
gene_1       5       0       3
gene_2       1       4       0
gene_3       0       2       6
  • 가로 방향은 행, 세로 방향은 열입니다.
  • 행렬의 모든 원소는 같은 자료형을 가집니다.
  • 전사체 count matrix는 보통 유전자가 행, 세포가 열입니다.

벡터와 행렬의 차이

구조 차원 선택 방법
벡터 1차원 values[position]
행렬 2차원 values[row, column]

행렬에서는 쉼표 앞이 행, 뒤가 열입니다.

matrix()로 행렬을 만든다

expression_matrix <- matrix(
  1:12,
  nrow = 3,
  ncol = 4
)

expression_matrix
  • 첫 번째 인자는 배치할 값입니다.
  • nrow는 행 수, ncol은 열 수입니다.

기본값은 열 방향으로 값을 채운다

matrix(
  1:12,
  nrow = 3,
  ncol = 4
)
     [,1] [,2] [,3] [,4]
[1,]    1    4    7   10
[2,]    2    5    8   11
[3,]    3    6    9   12

R은 기본적으로 한 열을 먼저 채운 뒤 다음 열로 이동합니다.

byrow = TRUE는 행 방향으로 채운다

matrix(
  1:12,
  nrow = 3,
  ncol = 4,
  byrow = TRUE
)

값을 읽는 순서에 따라 byrow 설정을 결정합니다.

값의 개수와 행렬 크기를 맞춘다

values <- 1:12

length(values)
3 * 4
  • 3행 4열에는 원소 12개가 필요합니다.
  • 값의 개수가 부족하면 R이 값을 반복해서 채울 수 있습니다.
  • 의도하지 않은 반복을 피하려면 크기를 먼저 확인합니다.

행렬의 구조를 확인한다

expression_matrix <- matrix(1:12, nrow = 3)

class(expression_matrix)
typeof(expression_matrix)
dim(expression_matrix)

dim()은 행 수와 열 수를 차례로 반환합니다.

행 수와 열 수를 각각 확인한다

nrow(expression_matrix)
ncol(expression_matrix)
length(expression_matrix)
  • nrow()는 행 수를 반환합니다.
  • ncol()은 열 수를 반환합니다.
  • length()는 전체 원소 수를 반환합니다.

행과 열에 이름을 붙인다

rownames(expression_matrix) <- c(
  "MS4A1", "CD3D", "LYZ"
)

colnames(expression_matrix) <- c(
  "cell_1", "cell_2", "cell_3", "cell_4"
)

expression_matrix

행과 열 이름은 각 값의 의미를 알려 줍니다.

rownames()와 colnames()로 이름을 확인한다

rownames(expression_matrix)
colnames(expression_matrix)
  • 행 이름은 유전자 이름처럼 관측 변수의 식별자일 수 있습니다.
  • 열 이름은 세포 바코드나 샘플 이름일 수 있습니다.

[행, 열]로 원소 하나를 선택한다

expression_matrix[1, 2]
expression_matrix["MS4A1", "cell_2"]

위치 번호 또는 이름을 사용할 수 있습니다.

한 행의 모든 열을 선택한다

expression_matrix[1, ]
expression_matrix["MS4A1", ]

쉼표 뒤를 비워 두면 모든 열을 선택합니다.

한 열의 모든 행을 선택한다

expression_matrix[, 2]
expression_matrix[, "cell_2"]

쉼표 앞을 비워 두면 모든 행을 선택합니다.

여러 행과 열을 선택한다

expression_matrix[
  c("MS4A1", "LYZ"),
  c("cell_1", "cell_3")
]

행 이름 벡터와 열 이름 벡터를 함께 사용할 수 있습니다.

한 행이나 열을 선택하면 벡터가 될 수 있다

one_gene <- expression_matrix["MS4A1", ]

class(one_gene)
dim(one_gene)

R은 결과의 차원이 하나만 남으면 기본적으로 벡터로 단순화합니다.

drop = FALSE로 행렬 구조를 유지한다

one_gene_matrix <- expression_matrix[
  "MS4A1",
  ,
  drop = FALSE
]

class(one_gene_matrix)
dim(one_gene_matrix)

후속 함수가 행렬을 요구할 때 유용합니다.

조건으로 행렬의 값을 선택할 수 있다

expression_matrix > 5
expression_matrix[expression_matrix > 5]
  • 비교 결과는 같은 크기의 논리형 행렬입니다.
  • 조건으로 선택한 최종 결과는 벡터가 됩니다.

행렬 연산은 모든 원소에 적용된다

expression_matrix + 1
expression_matrix * 2
expression_matrix / 10

벡터와 마찬가지로 산술 연산이 각 원소에 적용됩니다.

같은 크기의 행렬끼리 원소별 계산을 한다

matrix_a <- matrix(1:6, nrow = 2)
matrix_b <- matrix(7:12, nrow = 2)

matrix_a + matrix_b
matrix_a * matrix_b

같은 위치의 원소끼리 계산됩니다.

*는 원소별 곱셈이다

matrix_a * matrix_b

수학의 행렬 곱셈과는 다릅니다. 행렬 곱셈에는 %*%를 사용하지만, 이 과정에서는 원소별 계산을 중심으로 학습합니다.

rowSums()는 행별 합계를 계산한다

rowSums(expression_matrix)

전사체 행렬에서 행이 유전자라면 각 유전자의 전체 발현량을 계산합니다.

colSums()는 열별 합계를 계산한다

colSums(expression_matrix)

전사체 행렬에서 열이 세포라면 각 세포의 전체 count를 계산합니다.

행과 열 방향의 평균을 계산한다

rowMeans(expression_matrix)
colMeans(expression_matrix)
함수 계산 방향
rowMeans() 각 행의 평균
colMeans() 각 열의 평균

apply()로 방향과 함수를 지정할 수 있다

apply(expression_matrix, 1, max)
apply(expression_matrix, 2, max)
  • 두 번째 인자 1은 행 방향입니다.
  • 두 번째 인자 2는 열 방향입니다.
  • 합계와 평균은 rowSums() 등의 전용 함수를 우선 사용합니다.

전사체 count matrix의 방향을 기억한다

                세포 또는 샘플
             cell_1 cell_2 cell_3
유전자 MS4A1      5      0      3
       CD3D       1      4      0
       LYZ        0      2      6
  • 행: feature 또는 gene
  • 열: cell 또는 sample
  • 원소: 해당 유전자와 세포의 count

count matrix에는 0이 매우 많다

  • 단일세포 전사체 행렬의 많은 값은 0입니다.
  • 모든 0을 메모리에 저장하면 공간이 많이 필요합니다.
  • Seurat는 0이 아닌 값 중심으로 저장하는 희소 행렬을 사용합니다.
  • 희소 행렬의 실제 생성과 조작은 Seurat 부록 차시에서 다룹니다.

팩터는 범주형 데이터를 표현한다

conditions <- factor(
  c("control", "control", "treated", "treated")
)

conditions
class(conditions)

팩터는 값과 함께 가능한 범주의 목록을 저장합니다.

팩터의 범주를 수준이라고 한다

levels(conditions)
nlevels(conditions)
  • levels()는 수준 이름을 반환합니다.
  • nlevels()는 수준의 개수를 반환합니다.

문자형 벡터와 팩터는 다르다

condition_text <- c(
  "control", "control", "treated", "treated"
)

condition_factor <- factor(condition_text)

class(condition_text)
class(condition_factor)

팩터는 어떤 범주가 가능한지와 범주의 순서를 함께 관리합니다.

수준의 순서를 직접 지정할 수 있다

condition_factor <- factor(
  condition_text,
  levels = c("control", "treated")
)

levels(condition_factor)

그래프나 요약표에서 범주가 나타나는 순서에 영향을 줄 수 있습니다.

관측되지 않은 수준도 미리 지정할 수 있다

cell_types <- factor(
  c("B", "T", "T"),
  levels = c("B", "T", "NK")
)

cell_types
levels(cell_types)

현재 값에 NK가 없어도 가능한 범주로 유지됩니다.

table()로 수준별 개수를 센다

table(condition_factor)
table(cell_types)

관측되지 않은 수준은 개수 0으로 표시될 수 있습니다.

팩터의 일부를 선택해도 수준은 남을 수 있다

selected_types <- cell_types[cell_types != "NK"]

selected_types
levels(selected_types)

값을 선택하는 것과 수준을 제거하는 것은 서로 다른 작업입니다.

droplevels()로 사용하지 않는 수준을 제거한다

selected_types <- droplevels(selected_types)
levels(selected_types)

데이터를 필터링한 뒤 남은 범주만 필요할 때 사용합니다.

relevel()로 기준 수준을 바꿀 수 있다

condition_factor <- relevel(
  condition_factor,
  ref = "control"
)

levels(condition_factor)

통계 모델에서 어떤 범주를 기준으로 비교할지 정할 때 중요합니다.

팩터를 문자형으로 변환한다

as.character(condition_factor)

팩터의 표시값을 문자열로 사용할 때 명시적으로 변환합니다.

숫자처럼 보이는 팩터를 변환할 때 주의한다

score_factor <- factor(c("10", "20", "30"))

as.numeric(score_factor)
as.numeric(as.character(score_factor))
  • as.numeric(factor)는 내부 수준 번호를 반환합니다.
  • 실제 숫자값이 필요하면 문자형을 거쳐 변환합니다.

cluster identity는 팩터처럼 관리된다

cluster_ids <- factor(
  c("0", "0", "1", "2", "1"),
  levels = c("0", "1", "2")
)

levels(cluster_ids)
table(cluster_ids)

Seurat에서는 세포의 cluster identity도 수준이 있는 범주형 정보로 다룹니다.

cluster 이름을 세포 유형과 대응할 수 있다

cell_type_names <- c(
  "0" = "T cell",
  "1" = "B cell",
  "2" = "Monocyte"
)

cell_type_names

이름이 있는 벡터를 사용하면 기존 cluster ID와 새 세포 유형 이름을 대응시킬 수 있습니다.

흔한 오류 1: 행과 열의 순서를 바꾼다

expression_matrix["MS4A1", "cell_2"]

대괄호를 볼 때 항상 [행, 열]이라고 읽습니다.

흔한 오류 2: 존재하지 않는 이름을 선택한다

rownames(expression_matrix)
colnames(expression_matrix)

원소를 선택하기 전에 실제 행과 열 이름의 철자와 대소문자를 확인합니다.

흔한 오류 3: 선택 결과의 차원이 사라진다

expression_matrix["MS4A1", , drop = FALSE]

행렬 구조가 필요한 후속 작업에는 drop = FALSE를 사용합니다.

흔한 오류 4: 팩터를 바로 숫자로 변환한다

as.numeric(as.character(score_factor))

표시된 숫자와 팩터 내부 수준 번호를 구분합니다.

실습 1: 작은 발현 행렬 만들기

expression_matrix <- matrix(
  c(
    5, 0, 3,
    1, 4, 0,
    0, 2, 6
  ),
  nrow = 3,
  byrow = TRUE
)

행과 열 이름을 붙이고 구조를 확인합니다.

실습 2: 유전자와 세포 선택하기

expression_matrix["MS4A1", ]
expression_matrix[, "cell_2"]
expression_matrix[
  c("MS4A1", "LYZ"),
  c("cell_1", "cell_3")
]

각 선택 결과의 자료형과 차원을 확인합니다.

실습 3: 행과 열 방향으로 요약하기

rowSums(expression_matrix)
colSums(expression_matrix)
rowMeans(expression_matrix)
colMeans(expression_matrix)

어떤 함수가 유전자별, 세포별 결과를 만드는지 설명합니다.

실습 4: 조건과 cluster를 팩터로 만들기

conditions <- factor(
  c("control", "control", "treated"),
  levels = c("control", "treated")
)

cluster_ids <- factor(
  c("0", "1", "1"),
  levels = c("0", "1", "2")
)

각 팩터의 수준과 개수를 확인합니다.

오늘 배운 내용

  • 행렬은 같은 자료형의 값을 행과 열로 배치합니다.
  • 행렬 원소는 [행, 열]로 선택합니다.
  • rowSums()와 colSums()는 계산 방향이 다릅니다.
  • 팩터는 값과 가능한 수준을 함께 저장합니다.
  • 유전자 × 세포 행렬과 cluster factor는 Seurat 객체를 이해하는 기초입니다.
