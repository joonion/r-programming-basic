# 예제 데이터

## `sample_metadata.csv`

6차시의 CSV 파일 불러오기와 저장하기 실습에 사용하는 가상 전사체 샘플 메타데이터입니다.

- 실제 연구 대상이나 실험 결과에서 가져온 데이터가 아닙니다.
- 교육 목적으로 직접 만든 합성 데이터이므로 별도의 외부 데이터 라이선스가 적용되지 않습니다.
- `treated_2`의 `doublet_rate`는 결측값 확인 실습을 위해 비워 두었습니다.

| 열 이름 | 설명 | 자료형 |
|---|---|---|
| `sample_id` | 샘플 식별자 | 문자형 |
| `condition` | 실험 조건 | 문자형 |
| `batch` | 실험 배치 | 문자형 |
| `cell_count` | 품질 관리 후 세포 수 | 숫자형 |
| `median_genes` | 세포당 검출 유전자 수의 중앙값 | 숫자형 |
| `mito_percent` | 미토콘드리아 유전자 비율(%) | 숫자형 |
| `doublet_rate` | 추정 이중체 비율(%) | 숫자형 |
| `passed_qc` | 샘플 수준 QC 통과 여부 | 논리형 |

## `gene_expression.csv`

12차시 미니 프로젝트에서 사용하는 가상의 유전자 발현 데이터입니다.

- 실제 생물학적 시료나 공개 데이터에서 가져온 값이 아닙니다.
- 교육 목적으로 직접 만든 합성 데이터이므로 별도의 외부 데이터 라이선스가 적용되지 않습니다.
- 한 행은 유전자 하나, `gene_id`를 제외한 각 열은 `sample_metadata.csv`의 샘플 하나를 나타냅니다.
- 값은 조건별 평균 계산과 시각화 연습을 위한 임의의 발현량입니다.
- 정규화된 실제 발현량이나 차등 발현 분석 결과로 해석해서는 안 됩니다.

두 파일을 함께 사용할 때는 `sample_metadata.csv`의 `sample_id` 순서와 `gene_expression.csv`의 샘플 열 순서가 같은지 먼저 확인해야 합니다.
